\# God Intern Project Overview



God Intern is a Unity URP project focused on stylized rendering and technical art experiments.



Main modules:



1\. ASCII Post-Processing Pipeline

&#x20;  - URP ScriptableRendererFeature / ScriptableRenderPass

&#x20;  - Render Graph based full-screen post-processing

&#x20;  - Downscale passes

&#x20;  - DoG and Sobel edge detection

&#x20;  - Compute shader based edge analysis

&#x20;  - Glyph atlas based ASCII mapping

&#x20;  - Fill color and edge color controls



2\. PCG Terrain / Stylized Terrain Shader

&#x20;  - Noise-based vertex displacement

&#x20;  - Top / side color separation

&#x20;  - Fake lighting direction

&#x20;  - Toon-like highlight and shadow layering



3\. Stencil / Portal / Object Mode Shader Experiments

&#x20;  - Stencil writer / reader logic

&#x20;  - Depth and stencil attachment behavior in URP

&#x20;  - Render queue and compositing experiments

&#x20;  - Possible ASCII masking / object-only ASCII modes

Create an HTML technical review document that helps the project owner review Unity URP, Render Graph, shader syntax, pass structure, buffer flow, and algorithm implementation details.
